Adds products, projects, tasks and time entries to the Papierkram
import, and makes the work that is not billed yet in Papierkram billable
in Odoo. Installed automatically together with ``sale_timesheet``.

- The goods and services of Papierkram become products; services that
  Papierkram uses in time entries are billed by the time entries.
- Time entries without project ("Kein Projekt") go into one project per
  customer, "Retainer (customer)"; time entries of a Papierkram project
  into a project of that name. Each Papierkram task becomes a task of
  the project.
- Papierkram's export does not tell which time entries are billed. The
  list of time entries does: exported with the filter "Noch nicht
  abgerechnet", it gives the unbilled work. For it the import creates a
  confirmed sales order per customer with a line per service and rate;
  "Create Invoice" bills the time entries, and later time entries on the
  same task are billed on the same order.
- Every time entry keeps its Papierkram identity: a second import skips
  the time entries already present.

Use Cases / Context
===================

Papierkram bills time entries from its own time recording. When a
business moves to Odoo, the work done but not billed yet must stay
billable, and the history of time entries should stay available for the
projects. Odoo bills time entries through sales orders of
``sale_timesheet``; this module turns the unbilled work of Papierkram
into such orders.

Configuration
=============

- Install ``sale_timesheet`` (Timesheets with Sales); the module is
  installed automatically together with it and the Papierkram import.
- The goods and services of Papierkram become products with the VAT rate
  of Papierkram (none for a small business, the option *Small Business*
  of the import). Services used in time entries are invoiced by
  timesheets. The income account comes from the product category: check
  it after the import.
- Persons of the time entries without a user in Odoo get an employee of
  the same name in the company of the import; link them to users later
  if needed.

Usage
=====

1. In Papierkram open *Zeiterfassung → Einzelbuchungen*, choose the
   filters *Noch nicht abgerechnet* and *Gesamter Zeitraum* and click
   *CSV*.
2. Upload the file as *Unbilled Time Entries (CSV)* in the Papierkram
   import and choose the *Time Entries*: only the unbilled ones, all
   (history plus the unbilled ones as billable), or none.
3. After the import, *Sales Orders* lists the orders with the unbilled
   work; *Create Invoice* on an order bills it.

Odoo rounds the hours of a sales order line to two decimals; Papierkram
computes each time entry to the minute. An invoice can therefore differ
from Papierkram's amount by a few cents.

Known issues / Roadmap
======================

- Papierkram's export does not tell which time entries are billed: only
  the list of time entries exported with the filter *Noch nicht
  abgerechnet* gives the unbilled work. With *All Time Entries* the rest
  is imported as history.
- Time entries of a person without a user in Odoo get an employee of
  that name in the company of the import.
- Odoo rounds the hours of a sales order line to two decimals, so an
  invoice can differ from Papierkram's amount by a few cents.
